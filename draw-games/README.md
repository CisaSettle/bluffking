# 彩票与骰宝开奖源码

[中文 / English：完整说明与语言切换](index.html)

本目录公开双色球、大乐透、TOTO、快乐8、福彩3D、刮刮乐和骰宝的服务端开奖、中奖计算与结算相关源码，采用仓库根目录的 [AGPL-3.0-only 许可证](../LICENSE)。代码由上游逐文件同步，保留原始内容。

从 [彩票规则与抽样](src/lottery/rules.rs)、[开奖与派奖循环](src/lottery/draw_loop.rs)、[刮刮乐](src/lottery/scratch.rs) 和 [骰宝](src/sicbo_room/store.rs) 开始阅读。完整文件导航、随机数来源、依赖范围及验证限制见 [index.html](index.html)；下载目录后可用浏览器打开，并切换中文或英文。

这是源码公开目录，依赖部分未公开的服务端集成模块，不能单独编译运行。目前这些游戏没有承诺—揭示协议或可离线验证的开奖证明。开源让人检查算法，不能单独证明某次线上开奖执行了该代码。
