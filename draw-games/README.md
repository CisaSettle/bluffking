# 彩票与骰宝：公开过程，独立复核

[中文 / English：完整说明与语言切换](index.html)

本目录公开双色球、大乐透、TOTO、快乐8、福彩3D、刮刮乐、骰宝和鱼虾蟹的开奖输入、抽样、中奖计算源码，并提供独立离线验证器。采用仓库根目录的 [AGPL-3.0-only 许可证](../LICENSE)，公开内容由上游逐文件同步。

**生产核实（2026-10-25）：定期开奖证明已上线。**双色球、大乐透、TOTO、快乐8和福彩3D的公开证明接口均返回 `proof_status=available`，计划协议为 `bluffking-lottery-drand-v2-minute`；可按游戏与期号读取 [生产证明示例](https://app.bluffking.ai/api/draws/toto/29881827/proof)。本次生产发布标识为 `web-2026.10.25.68`，源码提交为 `08305a4af48208bafb9d1553ba0f367e64e109fd`。

刮刮乐、单人骰宝和骰宝房间的承诺与证明实现已包含在上述生产版本源码中；本次仅对定期开奖进行了公开接口取证，没有新购刮刮乐或下注骰宝。发布源码或标签本身仍不能证明线上运行的二进制。定期开奖只处理预先公开证明计划的期次；缺失证明时不补造承诺。刮刮乐只支持当前每张 1 金豆的福利卡和对应奖励证明。

炸金花早期的 `kind: "zjh"` 证明（公开服务器种子、没有玩家种子）已于 2026-11-01 停用，服务器不再提供这类证明；本验证器只保留对已保存旧证明的重算。此后的炸金花牌局改用 [`mental-poker`](../mental-poker) 的 `zjh-pf-shuffle-v2`：服务器先锁定加密牌组并作承诺，参与玩家的随机数决定发牌顺序，证明只打开请求者可见的牌，用 `pf_verify` 核对。两种方式下服务器在牌局中都知道牌面。

定期开奖在购买前固定未来 drand 轮次，验证签名后按公开规则生成号码；刮刮乐与单人骰宝使用预先承诺的服务器种子和浏览器玩家种子。骰宝房间在下注前承诺服务器种子，每笔投注随附浏览器生成的 32 字节玩家种子，开骰时把本轮所有结算投注的种子一起算入，最后一颗种子到达前服务器算不出骰子；服务器仍可在接受前拒收某笔投注；验证器无法确认每颗种子都来自真人下注者，应核对种子数等于本轮下注的真人数。鱼虾蟹现与骰宝共用这一算法和回执核对。骰宝金豆大奖可用投注种子和专属证明复算。鱼虾蟹旧证明保留当时只用服务器种子的验证范围。

俄罗斯转盘、老虎机、水果机、娃娃机和 2048 共用 [单人开奖验证协议](verifier/src/solo.rs)。服务器首先发出绑定局号的种子承诺，浏览器保存该承诺、玩家种子和下注／操作输入后再提交。服务器只受理该承诺一次，受理后的同一请求恢复同一结果。证明揭示后可复算轮盘号码和返还、老虎机符号和大奖、水果机跑灯与比倍、娃娃机抓取与大奖，以及 2048 初始随机种子。2048 的移动重放与入场费返还另由服务器记录。运营方仍可拒绝受理或中止请求。

[verifier/](verifier) 是后台代码与离线验证器共用的可独立构建规则库。从公开仓库根目录运行：

```sh
cargo build --locked --manifest-path draw-games/verifier/Cargo.toml
./draw-games/verifier/target/debug/draw-verify proof.json --receipt pre-draw-receipt.json
```

浏览器导出的 `{proof, receipt}` 文件可直接作为唯一参数。没有开奖前回执时仍能重算，但不能声称已与先前看到的承诺核对。验证器不联网，也不证明实际钱包入账、发布时间或部署身份。

完整协议、无需服务器的定期开奖重算、保存期限与源码导航见 [index.html](index.html)，默认中文，可切换 English。
