# 彩票与骰宝：公开过程，独立复核

[中文 / English：完整说明与语言切换](index.html)

本目录公开双色球、大乐透、TOTO、快乐8、福彩3D、刮刮乐和骰宝的开奖输入、抽样、中奖计算与结算相关源码，并提供独立离线验证器。采用仓库根目录的 [AGPL-3.0-only 许可证](../LICENSE)，公开内容由上游逐文件同步。

**本版本证明协议尚未部署到生产。**生成证明需要配套后台与客户端；发布源码或标签不能证明线上运行的二进制。定期开奖只处理预先公开证明计划的期次；缺失证明时不补造承诺。刮刮乐只支持当前 100 金豆福利卡和对应奖励证明。

定期开奖在购买前固定未来 drand 轮次，验证签名后按公开规则生成号码；刮刮乐与单人骰宝使用预先承诺的服务器种子和浏览器玩家种子。骰宝房间也提供承诺与揭示，但运营方仍预知结果，不能据此排除事前选种或中止风险。

[verifier/](verifier) 是后台代码与离线验证器共用的可独立构建规则库。从公开仓库根目录运行：

```sh
cargo build --locked --manifest-path draw-games/verifier/Cargo.toml
./draw-games/verifier/target/debug/draw-verify proof.json --receipt pre-draw-receipt.json
```

浏览器导出的 `{proof, receipt}` 文件可直接作为唯一参数。没有开奖前回执时仍能重算，但不能声称已与先前看到的承诺核对。验证器不联网，也不证明实际钱包入账、发布时间或部署身份。

完整协议、无需服务器的定期开奖重算、保存期限与源码导航见 [index.html](index.html)，默认中文，可切换 English。`src/` 保留原始服务端集成代码，依赖上游主服务，不能作为独立服务器构建；`verifier/` 不受此限制。
